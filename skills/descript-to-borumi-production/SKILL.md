# KundlasMD From Descript

Use when he says **make long video** or names a Descript project and wants a finished Kundlas MD video in Dropbox `/Borumi`. Do not ask him to export or drag files.

After intake, run [Kundlas MD Make Long Video](sand-workflow:kundlas-md-make-long-video) (the six steps). Also follow [Kundlas MD Video Production](sand-workflow:kundlas-md-video-production), [SMG YouTube Layout Pack](sand-workflow:smg-youtube-layout-pack), and [Kundlas MD Speaker Clear](sand-workflow:kundlas-md-speaker-clear).

## Hard rail

Original A/V only. One logo. No Shield. −14 LUFS on YouTube. Locked DISCLAIMER last. Plan first: chapters, captions, and assets (including Canva links) written before any file is made.

## Intake

1. Resolve the Descript project id.
2. Create `/Borumi/YYYY-MM-DD - <title>` with the packaged tree.
3. Pull media and transcript through Descript. Land sources in `01 Intake/Sources`.
4. Write brief + inventory. Privacy-scan.

Then run Make Long Video steps 1–6.
