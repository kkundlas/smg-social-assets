# KK1 vs KK2 — how to choose

Kulmeet’s guidance: kk1 is more complete, kk2 is more emotional; decide by topic.

| | **kk1-short** | **kk2-short** |
|---|---|---|
| Feel | Complete exam-room visit | Emotional contrast punch |
| Runtime | 60–90s | 30–45s |
| Spine | 5 chapter headings | PEACE letters P/E/A/C/E |
| Signature line | You shouldn’t have to… / You won’t have to… | shouldn’t vs wouldn’t (one sentence) |
| Best for | Nuance, next step, calm closure, labs/screening/meds | Misconception, false comfort, feed punch |
| Title | Kulmeet’s 3 formulas; 5 options ≤50 chars + Recommended | Same |
| Hook | Drive 09-hook first; Recommended spoken lines open the script | Same |
| CTA | None in script | None in script |

## Title formulas (both skills)
1. Action/Benefit: How to [Achieve Desire] Without [Pain Point]
2. Curiosity Gap: Why [Common Practice] is Actually [Unexpected Result]
3. Listicle: [Number] Warning Signs of [Problem] You Shouldn't Ignore

## Decision steps
1. If Kulmeet names kk1 or kk2, use that skill.
2. If the topic is mostly a misconception or false comfort → run [kk2-short](sand-workflow:kk2-short).
3. If the topic needs nuance, a clear next step, or calm closure → run [kk1-short](sand-workflow:kk1-short).
4. If unclear → default to [kk1-short](sand-workflow:kk1-short).
5. After choosing, follow that skill fully: **09-hook first**, then title pack (all 3 formulas represented), then script. The Recommended hook spoken lines go into the opening verbatim.

State the chosen mode and recommended/chosen title in the meta line.
