## AUTOMATIC PALETTE RULE (content purpose) — choose without asking Kulmeet

One **main palette per asset/campaign**. Keep related assets and revisions consistent (no random color cycling). Record **palette name + one-sentence reason** in project notes. **Do not ask for routine palette approval.**

### Priority (first match wins)
1. Explicit user request  
2. Genuine clinical warning section  
3. Special announcement / launch / promo  
4. Lifestyle (nutrition / exercise / sleep / stress / healthy habits)  
5. Patient instructions / routine practice / service / appointment info  
6. Default: general education / mixed / uncertain  

### Palettes

**Signature Teal** (default education / mixed / uncertain)  
- Background `#12343B`  
- Light text/panels `#F4F3EE`  
- Dark text `#231F20`  
- Accent `#F5D10A`  

**Calm Clinical** (patient instructions; routine practice / service / appointment)  
- Background `#F4F3EE`  
- Text `#12343B` or `#3C4651`  
- Decorative accent `#558BA5`  

**Warm Wellness** (nutrition / exercise / sleep / stress / healthy habits)  
- Background `#F4F3EE`  
- Text `#12343B`  
- Decorative accents `#788C5D` and `#DA7756`  

**Bold Attention** (special events / launches / promotional announcements — sparingly)  
- Background `#231F20`  
- Text `#FFFFFF`  
- Accent `#FF9900`  
- Support `#12343B`  

**Serious Alert** (genuine clinical warning sections **only**)  
- Background `#F4F3EE`  
- Text `#12343B` / `#231F20`  
- Labeled warning panel `#96151D` with off-white text  
- Disease topics alone are **not** warnings. Use words/symbols as well as color. Warnings may appear as an alert panel inside another main palette.

**No automatic navy alternative.**

### Color / type constraints
- Typography: **Bebas Neue** headings (short all-caps display); **Lato** body. Do not use Google Sans. Patient materials body ≥16px.
- Max **four designed colors** per asset (do not recolor photography or logos).
- Contrast: normal text ≥ **4.5:1**; large text ≥ **3:1**.
- **No yellow on white / off-white.** Sage / terracotta / steel-blue are decorative on light backgrounds unless contrast passes.
- Retired — never use: `#9A0718`, `#F72736`, `#0F62FE`, `#1F70C1`.

### Patient-facing copy locks
- Educational only; talk to your clinician.  
- Patient-facing name: **Dr. Kundlas** (never Dr. Kulmeet Kundlas).  
- List Sebring before Lake Wales when Shield contacts appear.
