# Kundlas MD video asset library

Copy finished Kundlas MD graphics into the reusable Dropbox library so later videos can steal them.

## Where
- Library root: `/Video Asset Kundlas MD`
- One title folder per video, named with the locked video title (no date prefix)
- Example: `/Video Asset Kundlas MD/7 Men's Health Numbers You Shouldn't Ignore`
- Production/edit copy stays in `/Borumi/YYYY-MM-DD - title`. Do not overwrite Borumi. Two copies on purpose.
- Do not dump into `Kundlas MD content` or `most used content in youtube videos`

## When
After Step 3 of [kundlas-md-make-long-video](sand-workflow:kundlas-md-make-long-video), when the planned set is on disk and before or after assemble. Do not wait for the 4K.

## Copy
Create the title folder plus `remotion`, `icons`, `napkin`, `hyperframes`, `higgsfield` as used.
Copy the full planned set for that job (talk-specific cards included so the job is complete).
Skip rejects, empty Hyperframes frame-0 posters, render scripts, and font/brand helper folders.
Keep each lane's `MANIFEST.md`.

## Mark reusable
Write `REUSABLE.md` in the title folder. Mark as steal-later:
- All Napkins
- All Hyperframes mp4s (and proof stills if useful)
- Icons
- Higgsfield loops/stills (never the doctor's face or voice)
- House DISCLAIMER and subscribe cards

Label remaining Remotion caption/text/chapter cards as this-talk only.

## After copy
Confirm counts. Tell the user the Dropbox path. Do not start the edit from this skill.
Do not create public Dropbox links. Do not delete or mix videos.
