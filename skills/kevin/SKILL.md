# Kevin — edit craft (two modes)

Recreate the **edit grammar** on **original A/V / original graphics only**. Never clone a reference creator’s face or voice. Never steal their footage or animation assets.

Pick a mode from the job:

| Mode | When | Reference |
| --- | --- | --- |
| **A — Long-form review** | Tech / product explainers, “I used this for months,” YouTube 16:9 | Better Creating https://youtu.be/wLdENoPC0fA (~17 min) |
| **B — Short allegory** | Vertical Reels / Shorts, “two types of people,” silent lesson in ≤10s | Facebook Little Line Stories #23 https://www.facebook.com/share/v/1ExNXJkzgH/ (~10s, 9:16) |

If the user says only “Kevin,” default to **Mode A** for long jobs and **Mode B** for vertical ≤15s comparison / motivational briefs.

# Mode A — Long-form dense review (16:9)

## Hard rails (A)

1. **Original A/V only** for the presenter.
2. **No dialogue captions** (no word-by-word lower-thirds).
3. **Hard cuts only** between A-roll and B-roll (no wipes/dissolves).
4. **Show, don’t tell:** named feature → visual proof within **3 seconds**.
5. **Cut dead air:** jump-cut A-roll; optional **~15–20% punch-in** on punchlines.
6. Music + UI SFX are part of the look. If brand forbids music unless asked (Kundlas MD), **ask first**; keep UI SFX if allowed.

## Format (A)

- Aspect **16:9**. Visual change about every **3–6s**. A-roll rarely >~10s without B-roll.
- Mix: clear VO; duck music ~−15 to −20 dB under vocal. Honor job loudness lock when set.

## Shot language (A)

| Layer | Look |
| --- | --- |
| **A-roll** | Static MCU / waist-up, centered, shallow DOF. Jump cuts kill breaths. |
| **B-roll (~60%)** | Macro product, hands-on, lifestyle/event POV, app screen in a real device. |
| **HUD / UI** | Neon green monospace; typewriter/fade; center or center-top; blip/key-click SFX on every hit. |

## Hook (A, first ~20s)

1. 0–10s: polarizing line over macros / teardown — no long logo.
2. ~10–20s: rapid product-in-context montage.
3. Hard cut to A-roll welcome.

## Chapter cards (A)

Full-frame **paper** cards: off-white texture, black sans, `#01` + title + thin rule. ~2–3s hold. Optional paper whoosh. Rhythm: hook → numbered sections → late honest tradeoff → CTA.

## End CTA (A)

A-roll left ~⅓; right ~⅔ paper board with taped “LEAVE A COMMENT!” / subscribe; handwritten soft CTA; arrows to YouTube end modules when publishing there.

## Assembly checklist (A)

1. Clean A-roll → jump-cut → punch turns.
2. Proof map: claim → B-roll/HUD/app timestamp.
3. B-roll density; paper chapter cards; UI SFX; no auto captions.
4. Paper split CTA; loudness QC; no cloned A/V.

## Mode A passes when

Dense hard cuts, ~60/40 B/A, zero dialogue captions, paper chapters, feature→proof ≤3s, punch-ins on turns, paper split end — original presenter A/V.

# Mode B — Short split-screen allegory (9:16)

Locked from Mmesoma Chukwu / Little Line Stories #23 — “The Lightning” / KEEP MOVING THROUGH UNCERTAINTY (~9–10s, 480×976 vertical). Entirely **2D minimal animation** in the reference (no talking head). Recreate the **structure**, not their art files.

## Hard rails (B)

1. **Original graphics / original filmed plates only.** Do not rip their stick figures, glow assets, or audio.
2. **Permanent top hook text** for the full runtime (e.g. `TWO TYPES OF PEOPLE`). Bold white all-caps sans, centered.
3. **Locked 50/50 vertical split** for the whole cut — left = stuck / fear path; right = keep-moving path.
4. **No VO** and **no dialogue captions.** Lesson is visual + final text only.
5. **Inciting SFX ≤2s** (thunder / hit / crack) synced to a shared conflict beat both sides react to differently.
6. Runtime target **~8–12s**. Resolve story by ~7s; hold payoff text ~2s for loop/share.
7. Music optional and faint; prefer **SFX bed** (rain, footsteps, one hard hit). Ask before music on Kundlas jobs.

## Beat map (B)

| Time | Picture | Sound / text |
| --- | --- | --- |
| 0:00 | Split on; same starting world both sides; top title already up | Soft rain / ambient |
| ≤0:02 | Shared conflict (lightning / failure / storm) | **Loud** hit SFX |
| Mid | Left: panic → shelter → stuck. Right: absorb hit → keep walking | Continuous foley |
| ~0:07 | Right palette shifts cold→warm (gold sun / glow); left stays dark | Faint resolve drone optional |
| Last ~2s | Bottom captions fade in: left lesson + right lesson | Hold; no subscribe bumper |

## Visual grammar (B)

- High-contrast mono base (black field, white line art + bloom/glow).
- Left stays cold/dark; right earns **gold / light** at resolution.
- Weather/environment overlays do the storytelling (rain, clouds, lightning flash-frames).
- Static wide “stage” — no zooms, punches, or jump cuts in the reference; motion is character/environment only.
- Payload text: clean white all-caps sans, opacity fade, bottom of each panel — one short line each.

## Live-action adaptation (B)

Same grammar without stick figures:

1. Film **two contrasting approaches** to one problem; lock permanent 50/50 split.
2. Static top comparison title for the whole short.
3. Shared failure/hit in first 2s with sharp SFX.
4. Left stalls; right continues; right gets warmer grade / light at the turn.
5. Fade in silent lesson lines in the final 2s. No VO explanation.

## Mode B passes when

9:16, ≤12s, permanent top hook, full-time split, early hard SFX conflict, left stuck vs right moving, cold→gold resolve on the right, silent dual lesson text at the end, original assets only.

# Shared out of scope

- Kundlas medical chapter-chip / disclaimer / logo rails → use house Kundlas skills.
- Cloning reference hosts, music stems, proprietary product footage, or third-party animation packs.
- Mixing Mode A chapter cards into a Mode B 10s Reel (don’t).

# Mode pick (one line)

- YouTube / Borumi long review → **A**.
- Facebook / Reels / Shorts comparison allegory → **B**.
- Ambiguous → ask once, or default A if runtime >60s else B.
