# TikTok explainer

Use when Kulmeet wants a how-it-works TikTok like KodeKloud’s “How ChatGPT Handles 900 Million Users” (https://www.youtube.com/shorts/fVLmyuCEEy8). Technique only — do not copy their logo, colors, ChatGPT marks, or script. Apply [Shield Medical brand](sand-workflow:shield-medical-brand) as accents. This is not the 7-beat [TikTok reel](sand-workflow:tiktok-reel) and not [TikTok list](sand-workflow:tiktok-list). Independent of Facebook. Never auto-publish.

Reference frames (if present): `/workspace/shorts-ref/crop/` `watch-01.png`…`watch-88.png`.

## Locked technique

1. Hook in the first second. Full-screen question. One visual metaphor. No intro card. No logo sting.
2. One diagram that grows. Start with the viewer’s object (pill bottle, plate, phone). Add one box at a time. Never dump the full stack on frame 1.
3. One idea per beat. About 6–10 seconds per new layer (tighter than Facebook).
4. Dark canvas: Deep Teal `#12343B` or near-black. Signal Yellow `#F5D10A` for the active flow. Cream labels. Crimson `#96151D` for the one warning.
5. Burned-in captions. Short phrases, matched to voice.
6. Recap zoom-out in the last 8–15 seconds.
7. One sourced number that makes it real. Never invent it.

## Shield / Kundlas MD version

- Topic shape: `How [everyday thing] actually works`.
- Default brand Shield. Kundlas MD only if he says this video is Kundlas MD.
- Patient-facing: Dr. Kundlas. Educational only in the caption.
- Runtime: 30–60s unless he asks longer. Do not default to 2:54.
- Original A/V only. Never clone face or voice.
- Music: optional Utope Rhythmic Reverie at 0.29–0.36 under the voice.

## Workflow

1. Topic + one hook question. Wait.
2. Beat list (8–12 beats): on-screen label, one sentence, what gets added. Wait.
3. Hand diagram/motion to Napkin or Visual Assets / Remotion. Do not invent a new renderer here.
4. Show the cut + caption. Wait. Do not post.
5. After yes: [Shield TikTok publish](sand-workflow:shield-tiktok-publish), `customScheduled`. Never `shareNow` unless he says post now.

## Never

Do not render before the beat list is approved. Do not start with a logo. Do not put the full diagram on screen at once. Do not invent stats. Do not post to Facebook from this skill.
