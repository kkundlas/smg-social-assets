# Original media video dress

## When to use
The user provided their own audio or audio+video and wants a finished, on-brand video. They forbid cloned voice or avatar.

## Rules
- Never generate or clone the presenter's voice or face.
- Use only the supplied take for speech. Trim, denoise, and caption it. Do not replace it.
- Apply the user's BRAND.md (Deep Teal `#12343B`, Signal Yellow `#F5D10A` on dark only, Warm Off-White `#F4F3EE`, Soft Black `#231F20`, Bebas Neue + Lato, max 4 colors, crimson only for urgent, 16px min on patient text).
- Every patient-facing piece includes: Educational only; talk to your clinician.
- Drop generated stills/motion into the named Descript project folders. Do not put assets on the timeline or publish unless the user asked.

## Lanes
- Napkin: diagrams and infographics.
- Higgsfield: generated B-roll or stills, not a fake presenter.
- Remotion: programmatic motion, captions, maps, lower-thirds.
- HyperFrames: HTML-to-MP4 motion. Visual Assets owns this.
- Descript: the edit. Import first. Timeline only if asked.
- Borumi: recorded clip ingest when the user supplies that file.

## Steps
1. Ingest the user's audio or A/V. Note duration, loud parts, and any on-screen text already in the take.
2. Transcribe. Build captions in Lato, high contrast, brand-legal color pairs.
3. List the 3–7 beats that need a visual. Assign each beat to one lane. Do not assign the same beat to two generators.
4. Generate those assets on-brand. Import to the Descript drop folders the user named (or the standing project).
5. If they asked for a cut: lay the original take on the timeline, drop visuals on the beats, add the teal lower-third (name + yellow rule), music bed if they supplied or approved one, export a review file. Do not publish.
6. Report what was generated, where it landed, and what still needs their take.
